the existing repository `StockObservation`. `inventory_eligibility` returns an
explicit reason with an `eligible` property; only `in_stock` is eligible.
`filter_inventory` preserves candidate ranking, removes duplicate candidates,
returns eligible SKU IDs and retains decisions for all unique candidates.
Missing rows and NULL quantities remain `unknown_stock`; zero is `out_of_stock`.

Freshness requires a caller-supplied `FreshnessPolicy(max_age=...)` and an aware
evaluation clock. Positive stock qualifies only when its source observation age
is between zero and the inclusive maximum age. Missing policy, invalid timestamps,
future observations, stale stock, invalid quantities and mismatched SKU records
cannot qualify. Quantity reasons take precedence over freshness reasons.
This module checks inventory only; callers must apply other recommendation gates.
